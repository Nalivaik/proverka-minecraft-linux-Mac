# CheatScan TUI

Консольный помощник для аудита Minecraft-клиента на Linux и macOS.
Скрипт собирает технические сведения и подозрительные совпадения в отчёт для последующей ручной проверки.

> Скрипт предназначен только для проверки систем и аккаунтов, на которые у вас есть разрешение.
> Он не удаляет файлы и не выносит автоматические решения о нарушении.

## Поддерживаемые системы

- Linux: Ubuntu/Debian, Fedora/RHEL, Arch, Alpine и другие Unix-подобные системы;
- macOS: Intel и Apple Silicon;
- POSIX shell (`sh`), без обязательного Bash.

Часть функций зависит от установленных системных утилит. Если утилита недоступна, соответствующий пункт будет отмечен как пропущенный.

## Запуск

```bash
chmod +x cheatscan_tui_v1.3.sh
./cheatscan_tui_v1.3.sh
```

Или без изменения прав файла:

```bash
sh cheatscan_tui_v1.3.sh
```

Для некоторых сведений о процессах, USB, системных журналах и автозапуске может понадобиться запуск с дополнительными правами. Не запускайте скрипт от root без необходимости: обычный запуск безопаснее и обычно достаточен.

## Возможности

В меню доступны:

1. Проверка совместимости команд и окружения;
2. Информация о системе, CPU, GPU, дисках и сети;
3. Поиск подозрительных JAR, архивов, библиотек и DLL;
4. Поиск совпадений в конфигурациях и логах за последние 14 дней;
5. Поиск каталогов Minecraft и лаунчеров;
6. Список установленных `mods`;
7. Поиск имён игроков в Minecraft-логах;
8. Recent, Trash и Downloads;
9. Поиск баз истории браузеров;
10. Java/Minecraft-процессы, библиотеки и сетевые соединения;
11. Опциональное сканирование строк дампа памяти на Linux;
12. Shell history;
13. Автозапуск и persistence;
14. USB и системные журналы;
15. Полное сканирование;
16. Просмотр текущего отчёта;
17. Справка по трактовке результатов;
18. Глубокое сканирование всего домашнего каталога;
19. Linux execution traces и загруженные модули;
20. История установки пакетов Linux.

## Отчёты

Отчёты автоматически сохраняются в:

```text
cheatscan_reports/
```

Формат имени:

```text
cheatscan_YYYY-MM-DD_HH-MM-SS.txt
```

Каждый завершённый раздел добавляется в текущий отчёт. Отчёт можно открыть обычным текстовым редактором или командой:

```bash
less cheatscan_reports/cheatscan_*.txt
```

## Дополнительные утилиты

Базовые проверки используют стандартные команды: `uname`, `find`, `grep`, `sed`, `awk`, `ps`, `stat` и другие.

Расширенные возможности используют доступные в системе утилиты:

- Linux: `journalctl`, `systemctl`, `ss`, `lsof`, `lsusb`, `lsblk`, `lscpu`, `lspci`, `sqlite3`, `gcore`, `gdb`, `strings`;
- macOS: `system_profiler`, `ioreg`, `launchctl`, `osascript`, `vmmap`, `sqlite3`, `lsof`.

Отсутствие необязательной утилиты не является ошибкой: проверка будет пропущена с пояснением.

## Интерпретация результатов

Красные совпадения — повод для ручной проверки, а не доказательство нарушения.

Более сильный сигнал — когда совпадают несколько независимых источников: файл находится в активном `mods` или instance-каталоге, упоминается как загруженный в Minecraft-логе, открыт процессом Java и имеет недавнюю дату изменения.

Более слабый сигнал — одиночное совпадение в старом архиве, Downloads, backup, кэше, истории команд или обычное событие подключения USB.

## Ограничения

- Скрипт не восстанавливает удалённые файлы;
- не разбирает полностью бинарный формат Jump Lists;
- не заменяет BAMParser, Registry Explorer, Prefetch-инструменты или антивирус;
- доступ к некоторым файлам и процессам может быть ограничен правами пользователя;
- названия модификаций и клиентов могут меняться, поэтому список сигналов нужно периодически обновлять.
